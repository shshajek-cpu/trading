# Trading

바이낸스 USDT-M 선물·현물, 업비트 원화 마켓, 주식·지수·환율·선물(야후 파이낸스) 실시간 차트. TradingView(tradingview.com/chart)의
화면 배치·조작·색을 따라 만든 웹 앱이다. 코드·아이콘은 모두 직접 작성했고, 차트 엔진은 TradingView의 오픈소스
[Lightweight Charts™](https://github.com/tradingview/lightweight-charts)를 쓴다. 실제 거래소 계정·주문 연동은 없다 —
대신 가상 계좌로 하는 모의 선물거래(바이낸스 선물 종목만)가 있다.

## 실행

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # 타입체크 + 프로덕션 빌드
npm run lint
```

## 화면

**데스크톱** — 상단 툴바 · 왼쪽 그리기 툴바 · 차트(최대 9칸 격자 — 레이아웃 메뉴에서 모양 그림 프리셋(1·2·3·4·6·8·9칸, 한쪽 크게 + 나머지 포함)을 고르거나 「직접 만들기」로 줄마다 칸 수를 정하고, 「내 레이아웃」에 격자와 칸 설정(심볼·주기·차트 종류·눈금·비교)을 이름 붙여 저장해 다른 기기에서도 쓴다. 칸 경계를 끌어 크기를 바꾸고 더블클릭하면 균등. 심볼·차트 종류를 모든 칸에 같이 적용할 수 있다. 십자선은 늘 모든 칸에 같이 보인다 — 같은 종목 칸은 커서 가격의 가로선까지, 다른 종목 칸은 같은 시각의 세로선만) · 하단 기간 바 · 오른쪽 위젯 바(관심 목록 등은 접힌 채 시작, 탭을 누르면 펼침).
버튼에 마우스를 올리면 이름 · 단축키 · 무엇을 하는지 설명이 툴팁으로 뜬다. 상단 바의 즐겨찾기 주기는 시간순(1m, 3m, 5m, 15m …)으로 놓인다.
**폰(≤900px)** — TradingView 앱처럼 아래 탭(관심 목록·차트·알림·탐색·메뉴)과 차트 아래 도구 줄
(심볼·주기 | + · ✎ · ⋯), 그 버튼들이 여는 아래 시트로 동작한다. 분할 레이아웃은 ⋯ → 레이아웃에서 고르고 PC 와 같은
격자를 쓴다(세로 화면에서 칸이 너무 좁으면 줄 방향을 뒤집어 보인다 — 좌우 2칸은 위아래로. 칸을 누르면 활성, "이 칸 크게 보기", "칸 크기 조절"로 경계 손잡이를 끈다). 칸이 좁으면 ⋯ → 레이아웃 또는 ⚙ 에서 "가격 축 표시"를 꺼
차트를 넓힐 수 있다(이 폰에만 적용). 배치와 디자인 규칙은 [UI-GUIDE.md](UI-GUIDE.md).

## 기능

**차트**
- 차트 유형 13종: 바, 캔들, 할로우 캔들, 볼륨 캔들, 라인, 마커 라인, 스텝 라인, 에어리어, HLC 에어리어, 베이스라인, 컬럼, 하이-로우, 하이킨 아시
- 주기 15종(1분~1개월), ☆ 즐겨찾기 주기는 툴바에 바로 표시. 숫자를 입력하면 주기 변경 상자가 뜬다(`5`, `60`, `1h`, `D`).
  거래소에 없는 주기는 작은 봉을 묶어 그리고, 그릴 수 없는 주기(야후 3d)는 메뉴·폰 시트·즐겨찾기·주기 상자에서 흐리게 꺼진다 —
  그 주기로 보던 칸을 그런 종목으로 바꾸면 일봉이 된다. 범례에 거래소(Binance·Upbit·NasdaqGS·KSE …)와 지연(「20분 지연」)이 붙는다.
- 가격 스케일 일반/로그/퍼센트/100 기준 + 자동 스케일, 심볼 비교(퍼센트 겹쳐 그리기 — 비교 중에는 퍼센트 눈금으로 고정)
- 기간 버튼(1일·5일·1개월·3개월·6개월·YTD·1년·5년·전체), 시간대 선택, 봉 마감 카운트다운
- 바 리플레이(시작점 선택 → 재생/한 봉씩 앞뒤/속도/시작점 다시 선택, 리플레이 중 심볼·주기를 바꿔도 같은 시각에서 이어짐), 스냅샷(PNG 다운로드·클립보드), 전체 화면, 미니창(PiP — 활성 칸을
  떠 있는 창으로 보여 준다. 보기 전용, 테마는 본 창을 따른다)
- 범례: 시고저종·등락, 지표별 값과 숨기기 · 설정(⚙, 이름 두 번 누르기, 또는 차트의 지표 선·막대 두 번 누르기) · 🔔 알림 · ✕ 삭제. 마우스는 줄에 올리면,
  폰은 줄을 누르면 버튼이 나온다. 지표 설정 창(입력·스타일 탭)은 바꾸는 즉시 차트에 보이고 취소하면 되돌린다.
  상단 바 범례 버튼(설정 ⚙ 왼쪽, 폰은 차트 모서리 ⚙ 시트)은 심볼 이름·시고저종 줄과 지표 이름 줄을 한꺼번에
  숨기고 보인다. 하나씩은 설정 → 상태 줄에서 켜고 끈다. 가격 칸의 지표 이름 줄은 접힌 채 시작한다(화살표 옆에 지표 개수) —
  화살표를 눌러 펴면 그 칸은 이 기기에서 펼친 상태로 기억한다.

**지표** — 이평선 · 거래량 급증 · RSI(세트 — 지표 하나로 멀티 이동평균은 가격 칸에, 거래량 급증·RSI 는 각자 칸에
그린다. 설정 창 한 곳에서 부분별 표시·값·색을 바꾸고, 범례의 어느 줄에서든 ✕ 하면 통째로 지운다),
거래량(급증 강조 옵션 — 기본 직전 70봉 평균의 3·5·7배, 단계별 색은 스타일 탭에서 바꾼다), 거래량 급증(직전 N봉 평균의 몇 배인지로 Lv1 메로나·Lv2 옐로우·Lv3 레드,
Lv2·Lv3 는 0 이면 끔, 배경 강조), 멀티 이동평균(선 6개, 기본 50·100·200·400, SMA/EMA, 선마다 색·굵기),
SMA/EMA/WMA/VWMA, 볼린저 밴드, VWAP, 일목균형표, 파라볼릭 SAR, RSI(70/30 밴드 밖으로 나간 구간을 과매수 초록·과매도 빨강으로 강조 —
선~기준선 사이 그라데이션, 나간 선 토막은 기준선을 넘는 자리부터 강조색으로 굵게, 그 봉들의 칸 배경은 멀리 나갈수록 진하게, 범례 값도 강조색.
70/30 선은 늘 보이게 자동 눈금에 넣는다. 스타일 탭에서 끄기·색 변경), MACD, 스토캐스틱, 스토캐스틱 RSI, ATR,
CCI, OBV, 윌리엄스 %R, MFI, ADX, 볼륨 프로파일(보이는 구간 — 가격대별 상승/하락 거래량, POC 선, 가치 영역 강조, 스크롤하면 다시 계산).
검색·즐겨찾기 가능한 지표 창(Enter 로 첫 결과 추가), 지표 템플릿 저장/적용.
지표는 진행 중인 봉도 1초마다 다시 계산한다. 지표를 지우거나 템플릿을 적용하면 토스트의 「되돌리기」로 되살린다.

**그리기** — 추세선·레이·정보 라인·연장 라인·추세 각도·수평선·수평 레이·수직선·교차선, 평행 채널·회귀 추세(±2σ 채널)·
피치포크, 피보나치 되돌림·추세 기반 피보나치 확장·피보나치 타임 존, 사각형·타원·삼각형·브러시, 텍스트·노트·화살표·화살표 표시,
롱/숏 포지션, 가격/날짜/날짜와 가격 범위, 고정 범위 볼륨 프로파일, 측정·확대 도구. 자석(약/강), 그리기 모드 유지, 전체 잠금/숨기기, 선택 도구바(색·굵기·스타일·
잠금·복제·삭제), 실행 취소/다시 실행, 객체 트리(행에 가격·시각 표시, 누르면 그 그림 선택). 수평선·수평 레이·추세선·레이·연장 라인·평행 채널·사각형·수직선에
알림을 걸 수 있다(선택 도구바·객체 트리의 종 버튼, 우클릭 「알림 켜기」·「알림 설정…」 — 아래 알림 참고).
잠근 그림은 Delete·지우개로 지워지지 않는다. 모든 그림을 숨긴 채 새로 그리면 숨김이 풀린다.
두 번 클릭해도, 누른 채 끌어도 그려진다(끄는 동안 미리보기). 켜 둔 도구 버튼을 한 번 더 누르면 꺼지고 십자선으로 돌아간다.
피보나치는 TradingView 처럼 시작점이 1, 끝점이 0. 롱/숏 포지션은 화면 크기에 맞춘 기본 목표·손절로 시작한다.
채널·피치포크: 플랫 톱/바텀, 분리 채널, 쉬프·수정 쉬프·인사이드 피치포크. 갠·피보나치: 피보나치 채널·속도 저항 팬·추세 기반 피보나치 시간·
피보나치 원·피치팬·피보나치 나선·속도 저항 호·피보나치 쐐기(레벨은 TradingView 기본값 고정 — 레벨 편집기는 없다), 갠 박스·갠 스퀘어 고정(만들 때 화면에서
정사각형)·갠 팬. 도형: 회전 사각형·경로(끝 화살표)·원·폴리라인·호·곡선·이중 곡선(곡선은 휨 손잡이를 끌어 모양을 바꾼다).
경로·폴리라인은 점을 계속 찍고, 마지막 점을 한 번 더 누르거나(두 번 클릭·두 번 탭) Enter·Esc 로 마친다. 폴리라인은 첫 점을 누르면 닫혀 안이 칠해진다.
패턴: XABCD·사이퍼·ABCD(되돌림·확장 비율 라벨), 헤드 앤 숄더(목선), 삼각형 패턴, 세 번의 드라이브, 엘리엇 충격파·조정파·삼각형·이중/삼중 조합(파동 번호),
주기선·시간 주기·사인선. 주석: 말풍선·코멘트·표지판(글은 텍스트·노트와 같은 편집기 — 두 번 누르면 고친다), 가격 라벨·가격 노트, 깃발 표시.
예측: 예측(목표 시각 안에 목표가에 닿으면 성공, 못 닿으면 실패), 바 패턴(두 점 사이 봉을 복사해 원본 바로 뒤에 흐린 봉으로 붙인다 — 봉은 그림에
저장돼 원본이 사라져도 남고, 끌어서 옮기고 끝점으로 가로 폭을 바꾼다. 최대 500봉), 프로젝션(A→B 대비 B→C 비율). 거래량 기반: 앵커 VWAP(누른 봉부터 지금까지,
±1σ·±2σ 밴드 선택, 새 봉마다 이어진다)·앵커 볼륨 프로파일(누른 봉부터 지금까지). 두 앵커 도구는 불러온 봉으로 계산하므로 앵커가 불러온 봉보다 앞이면
불러온 첫 봉부터 센다.

**모의 선물거래** — OKX USDT 무기한 규칙으로 바이낸스 시세에 가상 주문을 넣는다. 실제 돈·계정·API 키는 쓰지 않는다.
- 롱/숏 모드(한 종목에 롱·숏 포지션을 따로 보유), 교차/격리, 레버리지(OKX 공개 구간표의 코인별·크기별 최대치,
  OKX 에 없는 종목은 최대 20배·유지증거금률 2.5%), 수수료 메이커 0.02%·테이커 0.05%(바꿀 수 있음), 시작 잔고 10,000 USDT(초기화 가능).
- 주문: 지정가·시장가·조건부(최근 체결가 또는 마크 가격 발동 → 시장가/지정가), 진입과 함께 익절·손절, 종료 주문은 포지션 줄이기 전용.
  종료 탭의 % 는 누른 쪽(롱/숏) 포지션 수량 기준이다. 대기 주문으로 들어가면 「주문 접수」, 조건부 주문이 발동 뒤 거절되면 알림이 뜬다.
  시장가(시장가 종료·시장가로 발동하는 조건부 포함)는 주문하는 순간 바이낸스 호가창(50단계, 모자라면 100단계)을 훑어 평균 체결가로
  체결하고 슬리피지(bp)를 알려 준다. 호가창을 못 받으면 매수1·매도1 호가로 체결한다. 지정가는 가격을 뚫고 지나간 체결이 나오면 남은 수량이 모두,
  정확히 그 가격에서 난 체결이면 그 체결 수량만큼만 체결된다(부분 체결). 스프레드를 넘는 지정가는 넘는 만큼 바로 체결(테이커)되고 나머지가 걸린다.
  앱을 꺼 둔 동안(1분봉 되짚기)은 봉이 가격을 뚫고 지나갔을 때만 지정가를 체결한다.
- 강제 청산은 마크 가격 기준(격리: 그 포지션 증거금, 교차: 계좌 전체). 펀딩비는 바이낸스 펀딩 시각·비율로 정산한다.
- 화면: 오른쪽 위젯 「거래」 주문창, 차트 아래 거래 패널(거래소처럼 펼친 채 시작, 위쪽 경계를 끌어 높이 조절 —
  포지션·포지션 기록·미체결·주문 내역·체결 내역·자금 내역 탭과 오른쪽 자산 칸), 차트 위 진입가·익절·손절·
  미체결 주문 선(끌어서 가격 변경, ✕ 로 종료·취소)과 청산가 선, 우클릭 「여기에 지정가 …」. 폰은 차트 도구 줄의 거래 버튼(아래 시트).
- 포지션 기록: 끝난 포지션마다 진입·종료 평균가, 최대 수량, 가격 손익, 수수료, 펀딩, 순손익(수익률), 종료/강제 청산.
  자금 내역: 잔고를 바꾼 실현 손익·수수료·펀딩·강제 청산을 최신순으로.
- 앱을 꺼 둔 동안: 다시 열면 그동안의 1분봉(체결가·마크가)과 펀딩 기록으로 되짚어 체결·익절·손절·청산·펀딩을 처리한다.
  한 봉 안에서 익절과 손절이 모두 닿았으면 손절로 본다.
- PC·폰이 같은 계좌를 쓴다(Cloudflare D1, 개인 동기화 공간). 동시에 바꾸면 늦게 저장한 쪽이 서버 상태를 받아
  자기 동작을 다시 얹는다(이미 서버에 반영된 동작은 다시 얹지 않는다). 예전에 이 기기에만 두었거나 다른 코드로 쓰던 계좌는,
  서버에 계좌가 없으면 올리고 있으면 서버 계좌를 받아들인다(이 기기 계좌는 `trading.paper.backup.v1` 에 백업).

**관심 목록·알림** — 심볼 검색(전체/바이낸스 선물/바이낸스 현물/업비트/주식·지수 — 주식·지수 탭은 한글 이름('삼성', '코스피', '애플')과
야후 검색('AAPL', 'samsung')을 함께 찾는다, 시장 배지), 관심 목록(시장이 섞여도 된다. 정렬·끌어서 순서 변경, 폰은 ⋯ → 목록 편집),
심볼 상세(24시간 통계 — 업비트·주식은 전일 종가 대비 — ·기간 성과), 가격 알림(교차/상향 교차/하향 교차/보다 큼/보다 작음, 채널 진입/채널 이탈/채널 안/채널 밖
(두 경계 가격), 상승 %/하락 %(N분 안에 — 창 안의 최저가·최고가 대비, 최대 240분) + 메시지, 알림 창은 Enter 로 만들기).
교차 알림은 가격이 실제로 선을 넘어올 때 울린다 — 현재가와 같은 가격에 만들거나 울린 뒤 「다시 켜기」를 하면, 가격이 먼저 한쪽에 선 뒤에
건다(앱과 푸시 서버가 같은 규칙). 알림 목록의 연필로 가격·조건·메모를 고친다.
알림은 브라우저 알림 + 화면 토스트, 「앱 꺼도 알림 받기」를 켜면 가격·선·지표 알림이 앱을 닫아도 웹 푸시로 온다(메모 포함,
누르면 그 종목 차트가 열림). 푸시 서버는 동기화된 설정에서 매분 감시 목록을 읽으므로, 어느 기기에서 만들거나 고치거나 옮긴 알림이든
동기화되면 푸시를 켠 모든 기기로 온다. 1분마다 바이낸스 1분봉의 고가·저가로 판정해 1분 안에 닿았다 돌아온 가격도 놓치지 않는다
(바이낸스가 막히면 gate.io 시세로 대신한다 — 푸시 본문에 출처 표시). 알림을 만들거나 고치거나 다시 켠 뒤의 가격만 보고, 선 알림은
서버가 처음 본 뒤(켜거나 옮긴 뒤) 선을 넘을 때 울린다. 서버가 울린 한 번만 알림은 앱을 열면 그 기기에서도 울린 것으로 바뀌고, 그 뒤 「다시 켜기」하면 서버도 다시 감시한다.
화면에 없는 종목의 알림도 감시한다. 알림 목록의 행을 누르면 그 종목으로 가고, 울린 알림은
「다시 켜기」로 다시 건다. 지표 알림(범례 🔔 또는 알림 창의 "대상")은 지표의 선 값에 같은 조건과 트리거(한 번만/봉마다 한 번/봉 마감 시)를 건다.
앱이 열려 있으면 브라우저에서 계산해 울리고, 푸시를 켜 두면 앱을 닫아도 푸시 서버가 1분마다 같은 계산(알림에 저장된 지표 사본 — 과거 봉은
앱의 1000봉과 같은 값이 나오는 만큼만 읽는다: RSI 14 는 280봉, 창만 쓰는 SMA·BB 등은 창 길이, OBV·VWAP·PSAR 은 1000봉)으로
판정해 보낸다 — '한 번만'은 한 번, '봉마다'·'봉 마감 시'는 봉마다 한 번(앱이 이미 울린 봉은 건너뛴다). 서버의 CPU 한도 때문에 한 번에
(종목, 주기) 묶음 3개만 보고 분마다 돌아가며 보므로, 묶음이 N개면 묶음마다 ceil(N/3)분에 한 번 판정한다(예: 7개면 3분에 한 번) — 그만큼 늦게 오고,
1m 처럼 짧은 주기는 그 사이에 지나간 교차나 사이에 닫힌 봉을 놓칠 수 있다. 가격·선 알림은 이 제한 없이 매분 먼저 판정한다. 서버는 바이낸스가 막히면 gate.io 선물 봉으로
계산하고(푸시 본문에 표시), gate 에 없는 주기(3m·3d·1M)는 작은 봉을 바이낸스 경계로 묶어 만든다(이때 3m·3d 는 약 666봉, 1M 은 약 65봉 —
1M 에서 더 긴 봉이 필요한 지표(거래량 급증 기본 70봉 등)는 서버에서 값이 나오지 않아 울리지 않고, MACD 처럼 긴 평활은 값이 꽤 다를 수 있다).
그래서 서버 값은 바이낸스와 조금 다를 수 있다 — 거래량 기반 지표(거래량 급증 배율 등)가 특히 그렇다. 지표 검색은 영문 약칭(SMA·EMA·VWMA…)으로도 된다.
다른 시장의 알림도 같은 방식으로 서버가 본다 — 바이낸스 현물은 api.binance.com, 막히면 gate.io 현물 봉(3d·1M 은 일봉을 묶음), 업비트는 업비트 REST
(지표 봉은 한 번에 원본 봉 600개까지 — 2h 약 300봉, 3d 약 200봉), 주식·지수는 야후 차트 API(지표 봉은 60m 이 200일 창까지라 4h 약 270봉,
1m·3m 은 5일)를 부른다. 야후 1분봉은 장이 닫혀 있으면 봉이 없어 그동안 판정하지 않고, 늦게 오는 거래소(KRX 20분 등)의 마지막 봉은
아직 채워지는 중으로 본다. 야후 3d 는 주기가 없어 지표 알림을 걸 수 없다.

**고급 알림** — 모든 가격·선 알림은 트리거를 「한 번만」(울리면 꺼짐) 또는 「매번」으로 고른다. 「매번」은 울린 뒤 가격이 경계에서 「다시 걸리는 거리」
(기본 0.1%, 바꿀 수 있음)만큼 벗어났다가 조건을 다시 채우면 또 울리고, 「재알림 대기(분)」를 주면 그동안은 울리지 않는다(이동 % 는 울린 뒤의 움직임으로
다시 잰다). 알림마다 만료 날짜·시각을 줄 수 있다(기본 없음 — 지나면 「만료됨」, 앱·서버 모두 울리지 않는다; 지표 알림도 같다).
선 알림: 수평선·수평 레이는 그 가격, 추세선·레이·연장 라인은 두 앵커를 시간으로 이은 선의 그 시각 가격을 가격이 지나갈 때(레이는 시작점에서 두 번째 점
쪽으로만, 수평 레이는 시작 시각부터, 추세선은 두 앵커 사이만), 평행 채널·사각형은 경계 교차·진입·이탈(도형의 시간 구간 안에서만), 수직선은 그 시각이 되면
울린다. 조건·트리거·만료·메모는 알림 목록의 연필이나 우클릭 「알림 설정…」에서 고친다. 「새 수평선에 알림 자동 켜기」(기본 켬 — 알림 패널 아래
「알림 설정」과 차트 설정 → 알림)를 켜 두면 알림을 걸 수 있는 선·도형은 알림이 켜진 채 그려진다. 같은 곳의 「알림 소리」를 켜면 앱에서 울릴 때 짧은
소리(Web Audio)를 낸다. 알림 패널(폰은 알림 탭) 맨 아래 「알림 기록」은 최근 100개(시각·종목·문구·앱/서버)를 모든 기기가 함께 본다 — 앱이 울린 것은
바로, 서버가 푸시로 보낸 것은 앱이 서버를 확인할 때(열 때·탭으로 돌아올 때·푸시를 받았을 때) 더한다(같은 알림을 앱과 서버가 함께 울렸으면 한 번만).
서버는 「매번」 알림을 자기 판정 기록으로 따로 다시 걸고(앱과 서로 확인하지 않는다 — 앱이 열려 있으면 둘 다 울리고 OS 가 태그로 합친다),
기울어진 선은 1분봉의 시가를 봉 시작, 고가·저가를 봉 가운데, 종가를 봉 끝 시각의 선 가격과 견준다. 선 가격은 시간에 대한 직선이라, 로그 눈금이나
주말·장 마감으로 봉이 빈 주식 차트에서는 화면의 선과 조금 다를 수 있다.

**기타** — 다크/라이트 테마, 차트 설정(색·상태 줄·스케일·캔버스·시간대·알림), 빠른 검색(Ctrl+K — 기능·종목·지표),
TradingView식 우클릭 메뉴(차트 영역·그림·가격축·시간축)와 단축키(도움말: 메뉴 → 키보드 단축키),
핀·탐색·멀티 타임프레임, 기기 간 설정 늘 동기화, PWA 설치(새 버전은 토스트의 「새로고침」으로 적용). 동기화는 코드 입력 없이 모든 기기가
개인 공간 하나를 쓴다. 실제로 바뀐 것만 자동으로 올리고(속성 순서만 다른 재저장은 올리지 않음), 앱을 열 때·탭으로 돌아올 때·보이는 동안 15초마다
서버를 확인해 다른 기기에서 바꾼 설정을 새로고침 없이 받아 온다. 두 기기에서 따로 바꿨으면 멈추지 않고 마지막으로 맞춘 기준으로 3-way 합친다
(그림·알림·내 레이아웃은 id 별로 — 양쪽 추가는 모두 남기고 한쪽 삭제는 지우며 같은 항목을 둘 다 고치면 이 기기 것, 관심 목록은 집합, 차트 설정은 속성별,
레이아웃은 격자 모양을 통째로(두 기기 모양을 섞지 않는다) · 칸은 자리 번호별 · 칸 안은 속성별).
처음 맞추는 기기는 설정은 서버 것을 따르고 그림·알림·관심 목록·내 레이아웃은 합친다. 저장 버튼·Ctrl+S 는 「지금 동기화」이고 버튼의 점이 상태(동기화됨·동기화 중·오프라인)를
보여 준다. 동기화 창의 복구(서버 설정으로 이 기기 덮어쓰기 / 이 기기 설정으로 서버 덮어쓰기)는 확인 후에만 한다.

## 데이터 출처

API 키는 쓰지 않는다. 심볼 id 앞머리로 시장을 가른다(`src/lib/market/ids.ts`):
`BTCUSDT`(바이낸스 USDT-M 선물 — 예전부터 저장된 값 그대로), `BSPOT:BTCUSDT`(바이낸스 현물), `UPBIT:KRW-BTC`(업비트 원화),
`YF:AAPL`·`YF:005930.KS`·`YF:^GSPC`·`YF:KRW=X`·`YF:GC=F`(야후 — 주식·지수·환율·선물). 관심 목록·알림·그림·레이아웃은 이 id 로 저장·동기화된다.

**바이낸스 선물**(브라우저에서 직접)
- 캔들 `GET /fapi/v1/klines`, 심볼 `GET /fapi/v1/exchangeInfo`, 시세 `GET /fapi/v1/ticker/24hr`
- 실시간 `wss://fstream.binance.com/market/stream?streams={symbol}@kline_{interval}/{symbol}@aggTrade`, 시세 `{symbol}@miniTicker`
- 모의거래: 호가 `GET /fapi/v1/ticker/bookTicker`, 마크·펀딩 `GET /fapi/v1/premiumIndex`·`GET /fapi/v1/fundingRate`,
  되짚기 `GET /fapi/v1/markPriceKlines`·`GET /fapi/v1/aggTrades`, 실시간 `{symbol}@aggTrade`·`{symbol}@markPrice@1s`
- 모의거래 규칙: OKX 공개 API `GET /api/v5/public/instruments?instType=SWAP`·`GET /api/v5/public/position-tiers`

**바이낸스 현물**(브라우저에서 직접) — 캔들 `GET api.binance.com/api/v3/klines`(한 번에 1,000개), 심볼 `GET /api/v3/exchangeInfo`
(USDT·USDC·FDUSD·BTC 마켓, 검색 탭을 열거나 현물 종목을 볼 때만 받는다), 시세 `GET /api/v3/ticker/24hr?symbols=[…]`,
실시간 `wss://stream.binance.com:9443/stream`(kline·aggTrade·miniTicker). 요청 한도는 선물과 따로 센다.

**업비트**(브라우저에서 직접, CORS 허용) — 캔들 `GET api.upbit.com/v1/candles/{minutes/N|days|weeks|months}`(한 번에 200개라
처음 1,000개는 5번에 나눠 받고, 과거는 `to` 로 넘겨 가며 받는다), 마켓 `GET /v1/market/all`, 시세 `GET /v1/ticker`·`/v1/ticker/all?quote_currencies=KRW`,
실시간 `wss://api.upbit.com/websocket/v1`(체결로 진행 중인 봉을 만들고, 시세는 ticker). 업비트에 없는 주기는 묶어 만든다 —
2h·6h ← 60분봉, 8h·12h ← 240분봉, 3d ← 일봉(바이낸스와 같은 UTC 경계, 일봉 = 09:00 KST).

**야후 파이낸스**(주식·지수·환율·선물) — 브라우저는 CORS 로 막혀 있어 Pages Function 프록시 `/api/yahoo`
(`functions/api/yahoo.ts`, 개발 서버는 `vite.config.ts` 의 같은 처리기)를 거친다. 프록시는 차트(`/v8/finance/chart`)와 검색(`/v1/finance/search`)만,
정해 둔 파라미터만 넘기고 에지에서 잠깐 캐시한다(분·시간봉 5~10초, 일봉 이상 60초, 시세 15초, 검색 10분). 키·비밀값은 없다.
실시간 웹소켓이 없어 화면이 보이는 동안만 폴링한다(차트 7초, 관심 목록·시세 15초, 숨기면 멈춤). 3m 은 1m, 2h~12h 는 60m 을 장 시작
시각(09:30 등)부터 묶고, 3d 는 주지 않는다(메뉴에서 꺼짐). 장이 쉬는 시간·주말은 봉이 없어 차트에 그대로 빈다.
푸시 워커는 `query1.finance.yahoo.com` 을 바로 부른다.

## 라이선스 표기

Lightweight Charts™는 Apache-2.0이며, 화면에 TradingView 표기와 tradingview.com 링크가 필요하다.
차트 위 로고는 끄고, 메뉴(데스크톱 ≡ 서랍·폰 메뉴 탭) 맨 아래 "차트 엔진: TradingView Lightweight Charts™" 링크로 이를 충족한다.

## 주의

- 지역에 따라 바이낸스 접속이 막힐 수 있다. 이 경우 차트가 비고 범례의 연결 점이 빨갛게 남는다.
- 웹소켓이 끊기면 지수 백오프(1s → 30s)로 다시 붙고, 끊긴 동안의 공백은 캔들을 다시 받아 메운다.
- 바이낸스가 요청 제한(HTTP 429/418)을 걸면 `Retry-After`(읽을 수 없으면 429 60초, 418 5분) 동안 그 호스트(선물·현물 따로)로
  REST 요청을 아예 보내지 않고, 끝나면 한 번 다시 받는다. 관심 목록 시세 REST 폴링은 웹소켓이 끊겼을 때만, 탭이 보일 때만 돈다.
- 업비트는 캔들·시세 그룹마다 초당 10회(IP)라 요청 사이를 125ms 벌린다. 429 면 1.5초, 418 이면 1분 쉰다. 체결이 뜸한 코인의 1분봉은
  거래가 없던 분이 빠져 있다(업비트 캔들 그대로).
- 야후 보관 한도: 1m 은 최근 30일, 5m~30m 은 60일, 60m(과 그걸 묶은 2h~12h)은 730일까지만 과거가 있다 — 그 앞으로는 스크롤해도
  더 불러오지 않는다. 일·주·월봉은 상장 이후 전부. 한국(KRX)·일본·홍콩 등은 야후가 15~20분, CME 선물은 10분 늦게 준다 — 차트 메타에
  지연 값이 없어 거래소별 표(`yahoo.ts` 의 DELAY_MIN)로 범례에 「N분 지연」을 붙인다. 미국 주식·지수·환율은 실시간이다.
- 모의거래는 바이낸스 USDT-M 선물 종목만 된다. 현물·업비트·주식 차트에서는 주문창이 「이 시장은 모의거래를 지원하지 않습니다」를 보여 준다.
- 시세 조회용이다. 투자 판단 전에 거래소 화면과 대조하라.
